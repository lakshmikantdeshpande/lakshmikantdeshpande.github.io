# Lakshmikant Deshpande

Minimal personal website for GitHub Pages.

The site is intentionally plain static HTML and CSS:

- `index.html`
- `styles.css`
- `robots.txt`

There is no framework, package manager, build step, or Jekyll dependency.

## Local preview

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
