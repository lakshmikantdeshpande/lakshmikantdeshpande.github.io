I was at AppZen from February 2020 to August 2021 as a Senior Backend Engineer.

One of my main projects was a service that uploaded machine learning data to customer servers. It had grown customer by customer, so I rebuilt it as a configurable service where a new customer could be onboarded without code changes. I also built a document conversion service that turned different file types into PDF and replaced a paid third-party converter.

Other work included adding single sign-on, time tracking, and OCR to an internal image annotation tool. I also moved older callback code into another service and added multithreading to speed up report ingestion. The services were mostly Java with SQL databases and AWS queues.
