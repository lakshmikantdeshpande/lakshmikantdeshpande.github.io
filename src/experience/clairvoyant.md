I worked at Clairvoyant from March 2017 to February 2020 as a Software Engineer 2.

One project handled document processing and routing, where I wrote APIs to show document previews in the browser and added state management to the Angular app. On another project I built a reusable notification module that sent email, SMS, and web messages, including its database schema and a shared UI component.

I also worked on an order management app, where I rewrote slow SQL queries and built APIs and UI for user settings. A separate piece was Python tooling that scraped clinical trial websites and replaced a manual data collection process.
